# StarCraft II Asset Attribution

The icon and UI-panel image files under `mods/` in this directory (and the
identical copy under `gym_gui/assets/SMACv2/`) are unit portrait icons and
HUD console panel textures extracted from a local StarCraft II game
installation by the MOSAIC project maintainer, for use in MOSAIC's SMAC
and SMACv2 environment integrations.

**© Blizzard Entertainment.** StarCraft II and all associated game assets
(icons, textures, UI art) are the property of Blizzard Entertainment,
Inc. These files are included here to visually represent unit types and
UI chrome for the SMAC (StarCraft Multi-Agent Challenge) and SMACv2
research benchmarks, which are built on Blizzard's publicly released
StarCraft II AI/ML API:

- SMAC: https://github.com/oxwhirl/smac
- SMACv2: https://github.com/oxwhirl/smacv2
- StarCraft II API: https://github.com/Blizzard/s2client-proto
